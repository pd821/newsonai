OpenAI has brought Codex's computer use feature to Windows, the company announced Thursday, extending the AI agent's ability to "see" screens and execute tasks on behalf of users to Microsoft's operating system. The feature, which previously launched on Mac, means Codex can now interact directly with applications, files, and interfaces on both major desktop platforms.

The computer use capability is one of OpenAI's more concrete demonstrations of agentic AI — systems that can plan, execute, and iterate through multi-step tasks without continuous human guidance. When enabled, Codex can perceive what's on a user's screen and perform actions: clicking buttons, typing text, navigating menus, and executing workflows inside native applications.

## What It Means in Practice

For Windows users, the integration means Codex can handle desktop workflows that were previously the domain of specialized automation tools or human operators. OpenAI describes the capability as particularly useful for structured, repetitive tasks — data entry, document processing, form filling — but the company has been gradually expanding what the model can handle as its visual reasoning improves.

The addition of remote job management through the ChatGPT app is a practical extension. Users can set Codex to work on a task, leave the computer, and check results later — a dynamic that moves the feature closer to a true "async agent" rather than a co-pilot that requires continuous supervision.

OpenAI's move follows a broader industry trend toward AI systems that can operate across computing environments rather than living inside a chat interface. Google, Anthropic, and Microsoft have all made similar investments in agentic runtimes that can interact with real-world software on behalf of users.

## The Competitive Context

Codex's Windows expansion is the latest development in an intensifying race to build AI agents that can function as general-purpose digital assistants — capable of doing the work a human would do at a computer, just faster and without breaks. The commercial logic is straightforward: every task an AI can complete autonomously is a task a customer no longer needs to do themselves, which translates to both productivity gains and lock-in for the platform that gets there first.

Microsoft's own agentic ambitions are partially on display here: the company is reportedly building an AI super app that combines GitHub Copilot, Copilot Chat, Copilot Cowork, and a new capability internally called Autopilot into a unified experience. OpenAI's Codex running natively on Windows puts OpenAI's technology directly into that same environment — a dynamic that will be worth watching as both companies develop overlapping agentic products.

The computer use paradigm also raises the same questions it always has: what happens when an AI agent has access to your screen, your files, and your applications? Security researchers have flagged the expanded attack surface that comes with AI systems that can execute actions rather than just generating text. OpenAI says it has built in review and approval workflows, but the history of security features is a history of edge cases discovered in production.

For now, the feature is live for Codex users on Windows. OpenAI has not disclosed what fraction of its 4 million weekly Codex users are on the Windows platform, but given Windows' market share in enterprise environments, the number is likely material.
